# Ассемблер и интерпретатор УВМ

## 1. Общее описание

Ассемблер учебной виртуальной машины (УВМ), реализованный на Python для варианта 25.

Программа преобразует исходный YAML-файл с инструкциями УВМ в промежуточное представление (список словарей с полями `operation`, `A`, `B`, `C`), а затем — в машинный код. Результат сохраняется в бинарный файл.

Интерпретатор загружает машинный код в общую память УВМ, декодирует и выполняет инструкции, затем сохраняет выбранный диапазон памяти в XML-файл.

Ассемблер поддерживает четыре операции:

| Операция | Код | Назначение |
| --- | --- | --- |
| `LOAD_CONST` | 0 | Загрузка константы |
| `READ_MEMORY` | 1 | Чтение из памяти |
| `WRITE_MEMORY` | 5 | Запись в память |
| `LESS_THAN` | 6 | Сравнение «меньше» |

На **этапе 1** реализованы разбор YAML, проверка полей и формирование промежуточного представления.

На **этапе 2** реализованы кодирование команд, запись бинарного файла, вывод количества команд и отображение байтов в тестовом режиме. Каждая инструкция занимает 4 байта; используется порядок байтов `little-endian`.

На **этапе 3** реализованы интерпретатор, единая память команд и данных, цикл выполнения инструкций, загрузка константы, чтение и запись памяти, а также сохранение XML-дампа. Операция `LESS_THAN` пока не выполняется интерпретатором.

## 2. Описание всех функций и настроек

### Формат входного файла

Исходная программа описывается в YAML. Корневой ключ `commands` содержит список инструкций. Каждая инструкция включает:

- `operation` — название операции;
- `B` — числовое поле инструкции;
- `C` — числовое поле инструкции.

Поле `A` определяется автоматически по коду операции.

### Функции `src/assembler.py`

| Функция | Назначение |
| --- | --- |
| `check_number(value, name, maximum)` | Проверяет тип и диапазон числового поля |
| `parse_instruction(command)` | Преобразует YAML-команду в словарь с полями A, B, C |
| `assemble(source)` | Читает YAML и формирует список инструкций |
| `print_instructions(instructions)` | Выводит промежуточное представление (этап 1) |
| `encode_instruction(command)` | Кодирует одну инструкцию в четыре байта |
| `write_binary(instructions, output)` | Записывает машинный код в бинарный файл |
| `main()` | Обрабатывает аргументы, запускает ассемблер и выводит результат |

Для кодирования используются битовые сдвиги и побитовое ИЛИ. Поле `B` размещается начиная с бита 3. Поле `C` размещается начиная с бита 27 для `LOAD_CONST` и с бита 6 для остальных операций.

Основные константы: `OPCODES` — коды операций; `MIN_VALUE` — минимальное допустимое значение; `MAX_REGISTER` — максимальный номер регистра (7); `MAX_CONSTANT` — максимальная 24-битная константа; `INSTRUCTION_SIZE` — размер инструкции (4 байта).

### Функции `src/interpreter.py`

| Функция | Назначение |
| --- | --- |
| `create_memory()` | Создаёт список из 2048 нулей |
| `create_registers()` | Создаёт список из 8 регистров |
| `load_program(memory, filename)` | Загружает машинные команды в память и возвращает их количество |
| `decode_instruction(value)` | Извлекает поля A, B, C из машинной команды |
| `execute_instruction(command, memory, registers)` | Выполняет загрузку константы, чтение или запись памяти |
| `run_program(memory, registers, command_count)` | Последовательно декодирует и выполняет команды |
| `save_memory_dump(memory, filename, start, end)` | Сохраняет указанный диапазон памяти в XML-файл |
| `main()` | Обрабатывает аргументы и запускает интерпретатор |

Память команд и данных представлена одним списком целых чисел. Каждая машинная инструкция загружается из четырёх байтов в одну ячейку памяти. Счётчик команд `pc` увеличивается на единицу после выполнения инструкции. Для декодирования используются битовые сдвиги и побитовое И.

Основные константы: `MEMORY_SIZE` — размер памяти (2048 ячеек); `REGISTER_COUNT` — количество регистров (8); `INSTRUCTION_SIZE` — размер инструкции (4 байта).

### Аргументы командной строки ассемблера

| Аргумент | Назначение |
| --- | --- |
| `source` | Путь к исходному YAML-файлу |
| `output` | Путь к выходному бинарному файлу |
| `--test` | Вывод машинного кода на экран в байтовом формате без записи файла |

В обычном режиме программа записывает файл и выводит количество ассемблированных команд. В тестовом режиме выводит количество команд и байты каждой инструкции.

### Аргументы командной строки интерпретатора

| Аргумент | Назначение |
| --- | --- |
| `binary_file` | Путь к бинарному файлу программы |
| `dump_file` | Путь к выходному XML-файлу |
| `start` | Начальный адрес диапазона памяти |
| `end` | Конечный адрес диапазона памяти (включительно) |

## 3. Команды для сборки проекта и запуска тестов

### Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### Запуск ассемблера

```bash
python -m src.assembler tests/program.yaml program.bin
```

### Тестовый режим (вывод байтов)

```bash
python -m src.assembler tests/program.yaml program.bin --test
```

### Запуск на Windows

```cmd
run.bat
```

Поведение `run.bat` зависит от указанной в нём команды: для создания бинарного файла запускать ассемблер без `--test`.

### Сборка и запуск теста копирования массива

```bash
python -m src.assembler tests/copy_array.yaml copy_array.bin
python -m src.interpreter copy_array.bin dump.xml 50 55
cat dump.xml
```

### Запуск теста копирования массива на Windows

```cmd
tests\test_copy_array.bat
```

Скрипт собирает программу, запускает интерпретатор и выводит XML-дамп для визуальной проверки результата.

## 4. Примеры использования

### Пример исходной программы

Файл `tests/program.yaml`:

```yaml
commands:
  - operation: LOAD_CONST
    B: 59
    C: 3

  - operation: READ_MEMORY
    B: 0
    C: 4

  - operation: WRITE_MEMORY
    B: 4
    C: 3

  - operation: LESS_THAN
    B: 7
    C: 1
```

### Пример запуска в тестовом режиме

```bash
python -m src.assembler tests/program.yaml program.bin --test
```

Ожидаемый результат:

```text
Количество команд: 4
D8 01 00 18
01 01 00 00
E5 00 00 00
7E 00 00 00
```

### Пример создания бинарного файла

```bash
python -m src.assembler tests/program.yaml program.bin
```

Ожидаемый вывод:

```text
Количество команд: 4
Сохранено: program.bin
```

Файл `program.bin` содержит 16 байт (4 команды по 4 байта). Проверить его содержимое можно командой:

```bash
xxd -g 1 program.bin
```

Ожидаемые байты:

```text
D8 01 00 18 01 01 00 00 E5 00 00 00 7E 00 00 00
```

### Пример обработки ошибки

Если указать недопустимый номер регистра:

```yaml
commands:
  - operation: LOAD_CONST
    B: 59
    C: 8
```

Ассемблер завершится с сообщением об ошибке, указывающим на недопустимое значение поля `C` в первой команде.


### Пример работы интерпретатора (этап 3)

Файл `tests/copy_array.yaml` содержит 21 команду. Программа записывает массив `[6, 7, 8]` по адресам 50–52, затем копирует его по адресам 53–55 с помощью команд `LOAD_CONST`, `READ_MEMORY` и `WRITE_MEMORY`.

```bash
python -m src.assembler tests/copy_array.yaml copy_array.bin
python -m src.interpreter copy_array.bin dump.xml 50 55
```

Ожидаемый вывод:

```text
Количество команд: 21
Сохранено: copy_array.bin
Выполнено команд: 21
Дамп сохранён в dump.xml
```

Файл `copy_array.bin` содержит 84 байта (21 команда по 4 байта).

Ожидаемое содержимое `dump.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<memory>
    <cell address="50">6</cell>
    <cell address="51">7</cell>
    <cell address="52">8</cell>
    <cell address="53">6</cell>
    <cell address="54">7</cell>
    <cell address="55">8</cell>
</memory>
```

Значения по адресам 53–55 совпадают со значениями по адресам 50–52, что подтверждает корректность копирования массива.
