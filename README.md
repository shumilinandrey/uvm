# Ассемблер УВМ

## 1. Общее описание

Ассемблер УВМ, реализованный на Python.

Программа преобразует исходный YAML-файл с инструкциями УВМ во внутреннее представление в виде списка объектов `Instruction`.

Поддерживаются четыре операции:

| Операция     | Код | Назначение         |
| ------------ | --- | ------------------ |
| LOAD_CONST   | 0   | Загрузка константы |
| READ_MEMORY  | 1   | Чтение из памяти   |
| WRITE_MEMORY | 5   | Запись в память    |
| LESS_THAN    | 6   | Сравнение «меньше» |

На первом этапе реализованы разбор YAML, проверка полей инструкций и вывод промежуточного представления в тестовом режиме.

## 2. Описание всех функций и настроек

### Формат входного файла

Исходная программа описывается в YAML.

Корневой ключ `commands` содержит список инструкций. Каждая инструкция включает:

- `operation` — название операции.
- `B` — числовое поле инструкции.
- `C` — числовое поле инструкции.

Поле `A` определяется автоматически по коду операции.

### Функции src/assembler.py

| Функция                                | Назначение                                    |
| -------------------------------------- | --------------------------------------------- |
| `validate_field(value, name, maximum)` | Проверяет тип и диапазон поля                 |
| `parse_instruction(data)`              | Преобразует YAML-команду в объект Instruction |
| `assemble(source_path)`                | Читает YAML и создаёт список инструкций       |
| `print_instructions(instructions)`     | Выводит поля A, B, C                          |
| `create_parser()`                      | Настраивает аргументы CLI                     |
| `main()`                               | Запускает ассемблер и обрабатывает ошибки     |

Класс `Instruction` хранит название операции и значения полей `A`, `B`, `C`.

### Аргументы командной строки

| Аргумент | Назначение                         |
| -------- | ---------------------------------- |
| `source` | Путь к исходному YAML-файлу        |
| `output` | Путь к будущему бинарному файлу    |
| `--test` | Вывод промежуточного представления |

На первом этапе параметр `output` принимается, но файл не создаётся.

## 3. Команды для сборки проекта и запуска тестов

### Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### Запуск ассемблера

```bash
python -m src.assembler tests/program.yaml program.bin --test
```

### Запуск на Windows

```cmd
run.bat
```

## 4. Примеры использования

### Пример исходной программы

Файл `tests/program.yaml`:

```yaml
commands:
  - operation: LOAD_CONST
    B: 59
    C: 3

  - operation: READ_MEMORY
    B: 0
    C: 4

  - operation: WRITE_MEMORY
    B: 4
    C: 3

  - operation: LESS_THAN
    B: 7
    C: 1
```

### Пример запуска

```bash
python -m src.assembler tests/program.yaml program.bin --test
```

### Ожидаемый результат

```text
Количество команд: 4
LOAD_CONST: A=0, B=59, C=3
READ_MEMORY: A=1, B=0, C=4
WRITE_MEMORY: A=5, B=4, C=3
LESS_THAN: A=6, B=7, C=1
Бинарный файл появится на этапе 2.
```

### Пример обработки ошибки

Если указать недопустимый номер регистра:

```yaml
commands:
  - operation: LOAD_CONST
    B: 59
    C: 8
```

Ассемблер завершится с ошибкой:

```text
Ошибка: Ошибка в команде 1: Поле C должно быть от 0 до 7

```
